# Телецбург — сайт бургерной

Рабочая версия статического сайта бургерной «Телецбург», Санкт-Петербург, Народная улица, 5.

## Публичный сайт

После включения GitHub Pages сайт доступен по адресу:

<https://kirikxxx1-svg.github.io/Teletsburg/>

## Как изменить сайт

1. Откройте вкладку **Code** в этом репозитории.
2. Выберите `index.html`, `styles.css`, `app.js` или файл в `assets/`.
3. Нажмите кнопку с карандашом **Edit this file**, внесите изменения и нажмите **Commit changes** в ветку `main`.
4. GitHub Pages автоматически пересоберёт статический сайт. Обычно обновление занимает от нескольких секунд до нескольких минут.

Для текстов и ссылок используйте `index.html`, для цветов, размеров и адаптивности — `styles.css`, для интерактивных элементов (мобильное меню и слайдер) — `app.js`. Изображения лежат в папке `assets/`; пути к ним в коде менять не нужно, если файлы остаются там же.

## Локальная проверка

```bash
python3 -m http.server 8000
```

После запуска откройте <http://localhost:8000/>.
